# Corrección de preguntas familiares

Las preguntas «Quiénes son mis primos» y «Quién son mis primos» ya no se interpretan como declaraciones de identidad.

Cambios:
- El detector de «soy X» solo acepta declaraciones completas.
- Se bloquean expresiones como «soy mi...» o «soy mis...».
- Las preguntas familiares se detectan antes del cambio de interlocutor.
- Se usa la persona con la que Atlas habla actualmente.
- Las respuestas familiares filtran personas fallecidas cuando corresponde.
